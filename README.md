# RENATA CRM v4.0

Sistema de Gestión de Relaciones Comerciales para BMD Group.

## 🚀 Acceso Rápido

**Link en Vivo:** https://renata-crm-v4.onrender.com

## 📊 Funcionalidades

### Panel Administrativo
- Total de Clientes: 156
- Comisiones Pendientes: $45,230
- Proyectos Activos: 12
- Últimas Actividades en tiempo real

### Calculadora de Comisiones
- Monto de Venta (entrada flexible)
- 3 Tiers de comisión:
  - 1.2% - Comisión Estándar
  - 0.8% - Comisión Reducida
  - 3.0% - Comisión Premium
- Cálculo automático en tiempo real

### Dashboard de Ventas
- Ventas por Proyecto (gráficos con progreso)
  - Edificio Orión: $2.45M (35%)
  - La Joya de Malabrigo: $1.8M (26%)
  - Residencial Mochica: $1.2M (17%)
  - Laura San Isidro: $900K (13%)
- Comisiones Estimadas por tier
- Total Estimado: $331,500

## 🛠️ Stack Tecnológico

- **Frontend:** React + Vite
- **Estilos:** Tailwind CSS
- **Deployment:** Render
- **Repositorio:** GitHub

## 📦 Instalación Local

```bash
# Clonar repositorio
git clone https://github.com/BMDGROUP-SALES/Renata-crm-v4.git
cd Renata-crm-v4

# Instalar dependencias
npm install

# Desarrollo local
npm run dev

# Build para producción
npm run build
```

## 📝 Información de Comisiones

El sistema calcula automáticamente comisiones basadas en:
- Monto total de ventas
- Porcentaje seleccionado (1.2%, 0.8%, 3.0%)
- Proyectos activos de BMD Group
